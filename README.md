## 👋 About Me

I’m a **Software Engineer** focused on building **scalable, performance-oriented, and user-centric software** across the application, backend, and systems layers.

I enjoy working on software where product quality and engineering depth matter — from modern web applications and native interfaces to realtime services, AI-powered tools, cloud infrastructure, media pipelines, and developer platforms.

My engineering priorities are:

**Performance · Reliability · Security · Scalability · Maintainability · UX**

I prefer simple interfaces, clear architecture, measurable performance, and systems that remain easy to evolve.
